# 安装与冲突处理

## 交互安装

运行 `zsh ./setup.zsh` 后，界面会列出模块、平台支持情况和缺失依赖。输入编号可以切换模块，按 Enter 开始安装。

外部依赖缺失不会阻止安装，对应模块会显示为 `partial`。

## 命令冲突

安装器使用 Zsh 的 `whence` 检查待安装命令。如果当前环境已有同名 alias、函数或可执行文件，默认停止安装。

交互模式会列出冲突并要求输入完整的 `yes`。无交互模式必须显式传入 `--allow-conflicts`。

允许冲突只表示让 `zsh-tools` 在加载后提供最终定义，不会删除已有配置。

## 路径冲突

如果以下路径已存在但不属于当前工程，安装器会停止，不会自动覆盖：

- `~/.config/zsh-tools`
- `~/.local/bin/zsh-tools`

`.zshrc` 管理标记缺失、重复或不成对时也会停止安装。

## 卸载

```zsh
zsh-tools uninstall
```

卸载会备份 `.zshrc`，然后移除管理标记区、生成的配置和命令软链接。仓库、外部依赖、状态记录和备份均会保留。
